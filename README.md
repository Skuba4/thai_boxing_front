### ⚙️Ограничения
- Клиентская часть разрабатывалась под конкретный backend и его API-контракты.
- Проект не является универсальной заготовкой для повторного использования без адаптации.
- Большая часть реализации выполнена с применением AI-инструментов, поэтому в кодовой базе возможна неоднородность отдельных технических решений.
- При использовании проекта с другим backend потребуется адаптация API-слоя и части логики, связанной с комнатой соревнования.
- Полноценное автоматизированное тестирование в проект намеренно не добавлялось.

---
## 💡О проекте
Проект предназначен для автоматизации соревнований по тайскому боксу.

Система поддерживает базовый пользовательский цикл:
- регистрацию и вход;
- подачу заявки на получение статуса тренера;
- управление списком собственных спортсменов;
- создание и проведение собственных соревнований;
- подачу заявок на участие в чужих соревнованиях.
- заявка на получение статуса тренера подтверждается владельцем сервиса через административную часть системы.

Инструментарий проведения соревнований включает:
- обработку заявок на участие и судейство;
- формирование списка участников;
- составление пар и сеток соревнований;
- полный цикл судейского процесса с взаимодействием главного и боковых судей.

## ⚡Установка (требуется уже поднятый [backend](https://github.com/Skuba4/thai_boxing_drf))
### Локально
| Шаг | Команда / Действие                                                  |
|-----|---------------------------------------------------------------------|
| 1   | Установи [Git](https://git-scm.com), [Node.js](https://nodejs.org/) |
| 2   | `git clone https://github.com/Skuba4/thai_boxing_front.git`         |
| 3   | `cd front`                                                          |
| 4   | Создай файл `.env` на основе `.env.example`                         |
| 5   | `npm install`                                                       |
| 6   | `npm run dev`                                                       |
| 7   | Открой [http://127.0.0.1:5173/](http://127.0.0.1:5173/)             |


### Docker
